# Project Soul

## Vision
To build **Arcana: The Game of Prophecy** — a strategic, mystical trick-taking card game where foresight is power. We aim to create a premium, atmospheric digital experience that rewards precision over brute force, accessible on Web, Windows, and Mobile.
> **[Game Design Document](file:///d:/Dev/Arcana/docs/specs/GAME_DESIGN_DOCUMENT.md)**

## Principles
- **Precision over Power**: The core mechanic is accurate prediction (The Prophecy). The game design must reward exactness.
- **Mystical Atmosphere**: Every interaction, animation, and visual element should reinforce the "Dark Fantasy / Tarot" vibe. No generic UI.
- **Cross-Platform Excellence**: Seamless experience across touch (Mobile) and mouse (Web/Desktop).
- **Clean Architecture**: Strict adherence to MVVM (Model-View-ViewModel) with Provider for state management.
- **Code Quality**: "If you can't prove it works, you haven't built it." (Resonance Standard).
